Breadboard Basics

Learn the board engineers use to build circuits. Complete each mission to unlock the next step.

Keyboard: ← and → change steps, X shows underneath, T turns the tester on or off, N shows notes, F goes full screen. Presentation clickers that send Page Up and Page Down work too. In teacher mode, every step is unlocked. Switching to Student mode locks teacher mode again. To start a class with the sound off, share the link ending in #quiet.

A schematic is a map of a circuit. Each symbol stands for a part, and the lines are wires. Gray dashed parts haven’t been placed yet.
